# zzGearPlus (zz기어+)

전자 변속기(시마노 Di2 / 스램 AXS / L-TWOO·Wheeltop 등 ANT+ Shifting 지원 구동계)의
현재 기어를 **동심원**으로 보여주는 가민 엣지 데이터 필드.

대상 기기: Edge 540 / 550 / 840 / 850 / 1040 / 1050 / 1060 (CIQ 4.1+)

## 화면

- **10분할 한 칸** — 좌상단 기어 아이콘, 우상단 기어비(바깥쪽 끝에 배터리), 우하단 큰 기어 단수,
  왼쪽(칸 폭 1/3 지점)에 뒤 카세트 동심원
- **가로로 넓은 칸** — 타이틀 줄(아이콘 + 이름 + 기어비·배터리), 가운데 세로선 기준
  왼쪽 = 기어 단수, 오른쪽 = 앞 체인링 + 뒤 카세트
- **넓고 높은 칸** — 구동계를 가운데 크게, 맨 아랫줄에 단수·기어비·톱니수

동심원 규칙:

- 링 간격과 굵기는 균일. 안쪽 = 가벼운 기어(작은 톱니), 바깥 = 무거운 기어
- 현재 기어만 굵은 주황. 크로스체인이면 빨강 (아이콘·기어비도 같이 빨강)
- 회색 링의 진하기 = 그 기어에서 보낸 시간 (설정으로 끌 수 있음)
- 앞 체인링은 실제 치수대로 뒤보다 크게. 1x 구동계면 앞을 빼고 카세트를 가운데 크게
- 작은 화면(링 지름 64px 미만)에서는 링을 6개로 줄여 뭉개지지 않게 한다

## 데이터

- 1순위 `Activity.Info` 의 `frontDerailleur*` / `rearDerailleur*` (1 부터 센다)
- 2순위 `AntPlus.Shifting` 리스너 (`onShiftingUpdate`)
- 배터리는 `AntPlus.Shifting.getBatteryStatus()` 의 5단계 상태값.
  스램 AXS 등은 주지만 **시마노 Di2 는 ANT+ 로 배터리를 주지 않는다** (그때는 자리를 비운다)
- 뒤 1단이 가장 작은 스프라켓이라고 보고 그린다. 반대인 구동계는 설정 `뒤 1단이 가장 큰 스프라켓` 으로 뒤집는다

## 설정

| 설정 | 기본값 |
|---|---|
| 큰 숫자 (기어 단수 / 기어비) | 기어 단수 |
| 크로스체인 경고 (끄기 / 양 끝 한 단 / 양 끝 두 단) | 양 끝 한 단 |
| 뒤 1단이 가장 큰 스프라켓 | 끔 |
| 기어 아이콘 / 배터리 / 사용 시간 진하기 / 톱니수 | 모두 켬 |

크로스체인 경고는 색만 바꾼다(현재 링·아이콘·기어비 빨강). 넓고 높은 칸에서는 내장 폰트로 한 줄 문구가 더 붙는다.
풀 싱크로(Di2) · 시퀀셜(AXS)을 쓰면 시스템이 알아서 앞을 바꾸므로 경고를 꺼도 된다.

## 빌드

```powershell
tools\build-all.ps1      # 기기별 .prg
tools\export-iq.ps1      # 스토어 업로드용 .iq
```

폰트는 `tools/genfonts.py` (TitilliumWeb Bold), 기어 아이콘은 `tools/genicons.py` 로 만든다
(`tools/gear.svg` → 기기별 PNG, 화면에서는 `drawBitmap2` 의 tintColor 로 색만 바꾼다).
